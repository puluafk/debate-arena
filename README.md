# Debate Arena

Two AIs argue opposite sides of any topic.

- **FOR** vs **AGAINST** columns
- Multi-round debate (opening → rebuttal → closing)
- **OpenAI** and **Google Gemini** via your own API keys
- **Demo mode** works without a key
- Keys stored only in your browser; proxied through `/api/chat`

## Deploy (Vercel)

1. Import this repo on [vercel.com/new](https://vercel.com/new)
2. Deploy (no env vars required)

## Settings

1. Click **Settings**
2. Choose OpenAI or Gemini
3. Paste API key
4. Save
